# CatGame

## 📖 Описание проекта
Учебно-практический двумерный платформер, разработанный на языке C++ с использованием мультимедийной библиотеки SFML. Проект создан для закрепления навыков программирования на языке C++, отработки командного взаимодействия, освоения системы контроля версий Git и изучения базовых принципов геймдева (физика, коллизии, анимация, управление состояниями сцены).

## ⚙️ Технический стек
- Язык: C++ (стандарт C++17)
- Графический движок: SFML 2.6+
- Система сборки: GNU Make
- ОС: Ubuntu 22.04
- Управление версиями: Git, GitHub

## 🎮 Управление
`←` / `→` - Движение влево / вправо 
    `↑`   - Прыжок  
  `Enter` - Подтверждение выбора в главном меню 

## 📁 Структура проекта
├── func.cpp              # Игровой цикл, загрузка ассетов, инициализация сцены
├── movement.cpp          # Физика, обработка ввода, анимация персонажа
├── objects.cpp           # Создание объектов, расчёт хитбоксов, разрешение коллизий
├── game_menu.h / .cpp    # Логика и отрисовка главного меню
├── images/               # Графические ассеты 
├── Makefile              # Правила компиляции 
├── .gitignore            # Исключения для системы контроля версий
└── README.md             # Текущая документация

## 🛠 Сборка и запуск (Ubuntu)
1. **Установка зависимостей:**
   ```bash
   sudo apt update
   sudo apt install build-essential libsfml-dev
   ```
2. **Клонирование репозитория:**
   ```bash
   git clone   <https://github.com/X1miX/CatGame.git>
   cd <CatGame>
   ```
3. **Сборка и запуск:**
   ```bash
   В корне проекта:
   make - для компиляции
   make run - для запуска
